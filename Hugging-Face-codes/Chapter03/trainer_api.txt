we will explore on fine tuning a model uding TRAINER API
the main idea here is 
You already have a pretrained model and processed dataset. Trainer handles most of the training and evaluation workflow for you.

1.What is fine tuining?
Fine-tuning means taking a pretrained model and training it further on a smaller, task-specific dataset.

For example:

Pretrained BERT
    ↓
Fine-tune on sentence-pair dataset
    ↓
BERT that predicts whether two sentences are equivalent

The pretrained model already understands general language patterns. Fine-tuning teaches it a specific task.

2.what is a trainer API?
Trainer is a high-level Hugging face class that manages much of the training process.
For example:

Pretrained BERT
    ↓
Fine-tune on sentence-pair dataset
    ↓
BERT that predicts whether two sentences are equivalent

The pretrained model already understands general language patterns. Fine-tuning teaches it a specific task.

With Trainer, you mostly provide:

The model

Training dataset

Validation dataset

Training configuration

Tokenizer/processing class

Data collator

Optional metrics function

then you call:
trainer.train()
important trainer doesnot remove the underlying Pytorch concepts.

Internally it still performs:
Forward pass

Loss calculation

Backpropagation

Optimizer updates

Batching

Evaluation

Checkpoint saving

Learning-rate scheduling

It simply manages them for you

3. Complete workflow

The overall workflow is:

Load dataset
    ↓
Load tokenizer
    ↓
Tokenize dataset
    ↓
Create dynamic padding collator
    ↓
Define TrainingArguments
    ↓
Load pretrained model
    ↓
Create Trainer
    ↓
Train model
    ↓
Evaluate model
    ↓
Save model/checkpoints
