    Pipeline is a high level API that lets you use a pre trained model for a specific task with vey little code:
    Think of it as 

    Your text
    ↓
    pipeline()
    ↓
    Tokenizer
    ↓
    Model
    ↓
    Post-processing
    ↓
    Result

    Instead of manually doing all of these steps, pipeline() does them for you.

Why is it called a pipeline?
Because there are multiple processing stages:

Input
 ↓
Preprocessing
 ↓
Model
 ↓
Postprocessing
 ↓
Output

How does a Transformer work?

The simplest way to think about a Transformer is:

A Transformer takes tokens, repeatedly lets them look at each other using attention, processes the information with FFNs, and finally predicts something.

"I love playing cricket"
          ↓
      Tokenizer
          ↓
   Token IDs
          ↓
    Embeddings
          ↓
 Positional information
          ↓
 ┌─────────────────────┐
 │ Transformer Block 1 │
 ├─────────────────────┤

 ├─────────────────────┤
 │ Transformer Block 3 │
 ├─────────────────────┤
 │         ...         │
 ├─────────────────────┤
 │ Transformer Block N │
 └─────────────────────┘
          ↓
      Final Norm
